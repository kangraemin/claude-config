# LINE 움직이는 스티커 통과 기준 (상위 20세트 160개 분석, 2026-11-28)

## 왜 잘 팔리나
- 단순 호감 캐릭터: 머리:몸 ≈ 1:1(0.8~1.3), 통통한 덩어리 몸, 점 눈, ω 입, 볼터치.
- 프레임마다 손으로 다시 그림 → 선 끓음(같은 자세도 윤곽 0.5~3px 차이). 평행이동·회전만으로 만든 프레임 없음.
- 동작 작고 부드러움: 키포즈 2~5개 A-B 반복 또는 등장→유지→복귀. 팔·표정만 바뀜.
- 짧은 루프 1.0~2.0초(중앙 1.4), 8~20프레임(중앙 13), 프레임 66~167ms(대부분 100ms). 첫 프레임 = 완성 상태(썸네일).
- 일상 쓰임 분명(사랑·하트 최다, 인사·감사·대답, 일상 행동, 응원, 리액션).
- 소품·이펙트(하트·음표·별·꽃, 손그림)로 감정 즉시 전달. 하트 크기 작음→큼→작음.
- 글자 약 40%: 상단, 1~2줄, 굵은 둥근 고딕+외곽선, 타이핑·페이드·±2px 흔들림.

## 해부 (가장 자주 틀리는 곳)
- 팔: 짧고 굵은 튜브, 끝은 둥근 뭉툭(손가락 없음). 몸통 옆 외곽선에서 나옴, 어깨 높이 = 턱 바로 아래~몸통 위 1/3.
- 팔 내림: 손은 몸통 외곽선 바깥 옆, 허리~엉덩이 높이. 얼굴 앞에 뜨는 손 절대 없음.
- 흔드는 팔: 몸 옆에서 바깥·위로 솟는 한 줄 곡선, 팔뿌리가 몸통에서 이어지는 선이 항상 보임. 얼굴 쪽이면 볼·귀 옆 머리 외곽에 겹침.

## 판정표 (하나라도 실패면 다시)
- A 파일: 프레임 8~20 / 총 1.0~2.0초 / 66~167ms 프레임 85%+ / 루프 이음(끝→처음 변화 ≤ 평균의 1.5배) / 투명 배경 / LINE 규격 320×270 이하·1MB 미만.
- B 화면: 알파 채움 0.20~0.35 / bbox 너비·높이 0.50~0.88 / 가장자리 2px 비움 / 점프 외 크기 변화 ±15%.
- C 동작: 서로 다른 자세 3~12 / 선 끓음 있음 / 팔 형태 바뀌는 프레임 2+ / 소품·이펙트 1+ (크기·위치 변화).
- D 선·색: 선 굵기 캔버스 높이 1.2~2.0%·일정 / 순흑 또는 진갈색 / 단색 평면, 그라데이션·광택·3D 금지 / 캐릭터에 흰 외곽 없음.
- E 해부·AI티: 팔2·다리2·귀·꼬리 개수 고정 / 팔 연결(위 해부) / 손 위치 / 손가락 없음 / 의도 안 한 비대칭 없음 / 지나치게 매끈한 벡터 아님(선 떨림, 면이 선과 살짝 어긋남) / 부품 이음매·이중선 없음 / 프레임 간 같은 캐릭터.
- F 글자: 1~2줄, 줄 높이 12~15%, 얼굴과 안 겹침, 첫 프레임에 완성.
