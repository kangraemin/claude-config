# 1차 블라인드 결과: 검사자 2명 모두 우리 3개를 정확히 가짜로 골랐다. 아래를 전부 고쳐 out/ 를 다시 만들어라. 전부 네가 직접(image_gen 그림 + 조립).

## 두 검사자 공통 지적
1. 선 끓음 없음: 같은 자세 프레임이 픽셀까지 똑같다(복붙). 진짜는 프레임마다 손으로 다시 그려 선이 미세하게 다르다.
   - 같은 자세를 재사용하지 말고 프레임마다 image_gen으로 다시 그린 그림을 쓰거나, 최소한 같은 자세가 두 번 나오면 다른 그림으로 바꿔라.
2. 선이 벡터처럼 완벽히 균일·매끈하다. 마커 손그림처럼 굵기가 살짝 흔들리고, 면이 선과 살짝 어긋나게.
3. 움직임이 팔 하나 평행이동/하트 스케일뿐이다. 몸·머리도 동작에 따라 살짝 기울고 눌리고(스쿼시) 귀·더듬이가 따라 흔들려야 한다.
4. 이펙트(하트·반짝이)가 켜졌다 꺼질 뿐. 손으로 그린 이펙트가 날아오르거나 튀어나오는 움직임이 있어야 한다.

## 컷별
- 01 인사: 흔드는 팔이 몸통 옆구리에서 평행이동하듯 보인다. 반대쪽 팔이 프레임마다 있다 없다 한다 — 반대쪽 팔은 항상 몸 옆에 보이게. 흔드는 팔은 어깨(턱 바로 아래 몸통 옆)에서 시작해 손목이 꺾이며 흔들리게.
- 02 고마워: 두 손을 턱 밑 얼굴 앞에 모은 자세가 팔이 턱 밑에 붙은 것처럼 보인다 → 두 손을 가슴(배 위) 앞에 모으거나 꾸벅 인사로 바꿔라. 하트가 캔버스 위 가장자리에서 잘린다 → 가장자리 여백 확보.
- 03 OK: 엄지척이 가운뎃손가락처럼 보인다 → 손가락 쓰지 말고 둥근 손으로 머리 위 동그라미(OK) 만들기로 바꿔라. 팔이 허리에서 솟는다 → 어깨에서.
