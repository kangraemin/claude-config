# 과제: LINE 움직이는 스티커 — 상위 20세트와 섞여도 구별 안 되는 GIF/APNG

## 자료
- bench/ : LINE 움직이는 스티커 판매 상위 20세트(폴더 01-*~20-*, 세트당 APNG 8개). stats.json에 수치.
- 측정 요약: 프레임 중앙 13.5(8~20), 한 바퀴 1.0~2.0초(중앙 1.5), 서로 다른 그림 중앙 5장, 가변 프레임 시간 37%.

## 할 일 (전부 네가 직접: 분석·그림(image_gen)·조립)
1. bench APNG를 프레임으로 풀어 직접 보고, 왜 잘 팔리는지 분석해 ANALYSIS.md에 적어라.
   - 캐릭터 종류, 비율, 선·채색, 팔다리를 그리는 법, 동작 기법, 글자 유무, 세트 구성.
   - 팔은 특히 자세히 적어라: 어깨가 몸 어디에서 나오는지, 팔을 내리면 손이 어디에 있는지, 흔드는 팔은 어떻게 그리는지.
2. 분석을 근거로 새 오리지널 캐릭터를 정해라. 시바·기존 bench 캐릭터 베끼기는 금지.
3. 스티커 3개(인사, 고마워, OK)를 만들어라.
   - 각 스티커의 모든 프레임을 image_gen으로 그려라. 한 장의 시트에 프레임을 순서대로 같이 그리면, 같은 캐릭터·같은 선이 나온다.
   - 몸과 머리는 프레임마다 같은 그림이어야 하고, 팔·표정·효과만 바뀌어야 한다.
   - 팔은 몸통 옆 어깨에서 나와야 한다. 팔을 내리면 손이 몸 옆에 와야 한다. 팔다리 개수가 정확해야 한다.
   - 시트를 잘라 프레임을 맞추고, 투명 배경 APNG로 조립해라. 규격: 320×270 이하, 5~20프레임, 1MB 미만, 4초 이내, 반복 1~4회. 미리보기 GIF(흰 배경)도 함께 만든다.
   - 파일 이름: out/01.png, out/01.gif, out/01-frames.jpg (02, 03도 같은 형식).
4. 스스로 검사해라.
   - 모든 프레임을 실제 크기로 보고 팔다리 개수, 어깨 위치, 손 위치, 선 끓음, 프레임 사이 튐을 확인한다.
   - bench와 나란히 놓고 비교한다.
   - 하나라도 틀리면 다시 그린다.
5. 끝나면 out/ 파일 목록과 각 스티커의 프레임 수·시간을 출력해라.

## 6. 통과 기준
- CRITERIA.md 의 판정표를 모두 통과해야 한다. 특히 E(팔 연결·손 위치).
